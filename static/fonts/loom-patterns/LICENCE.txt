THE PATTERN IS THE LETTER
  These are display faces. Each glyph is a heavy grotesk silhouette with a
  pattern worked through it — ribbons in Organic, a crackle mesh in Retro, a
  hairline scribble in Linear, speckle and scattered flowers in Flora. Below
  roughly 40px the pattern stops resolving and the letter goes with it. Set
  them large: headlines, posters, titles. Not body copy, not captions, not
  interface labels.

CAPS ONLY
  There is no lowercase in any cut. Lowercase codepoints are mapped to the
  capitals, so a lowercase string still types — it just sets as caps.
